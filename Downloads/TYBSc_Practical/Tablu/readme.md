# 1\. Basic Tableau Questions

### Q1. What is Tableau?

**Answer:** Tableau ek Data Visualization tool hai jiska use data ko analyze karne aur charts, graphs aur dashboards banane ke liye kiya jata hai.

### Q2. What is Data Visualization?

**Answer:** Data Visualization ka matlab data ko graphs, charts aur maps ke through visually represent karna hai.

### Q3. What is a Worksheet?

**Answer:** Worksheet ek jagah hoti hai jahan hum individual chart ya visualization banate hain.

### Q4. What is a Dashboard?

**Answer:** Dashboard multiple worksheets ka collection hota hai jo ek hi screen par display hota hai.

### Q5. What is a Story in Tableau?

**Answer:** Story multiple visualizations ka sequence hota hai jisse hum data ki insights explain karte hain.

### Q6. What is Tableau Public?

**Answer:** Tableau Public ek free platform hai jahan hum apne visualizations online publish aur share kar sakte hain.

### Q7. What is the Show Me feature?

**Answer:** Show Me Tableau ka feature hai jo hume different charts aur visualizations select karne mein help karta hai.

# 2\. Data \& Visualization Questions

### Q8. What is a Dimension?

**Answer:** Dimension qualitative data hota hai jo data ko categories mein divide karta hai.

**Examples:** Category, Region, Customer Name.

### Q9. What is a Measure?

**Answer:** Measure numerical data hota hai jis par mathematical calculations perform kar sakte hain.

**Examples:** Sales, Profit, Quantity.

### Q10. What is a Bar Chart?

**Answer:** Bar Chart bars ki help se different categories ki values ko compare karta hai.

### Q11. What is a Line Chart?

**Answer:** Line Chart data points ko lines se connect karta hai aur time ke saath trends dikhata hai.

### Q12. What is a Pie Chart?

**Answer:** Pie Chart ek circular chart hota hai jo data ko different slices mein represent karta hai.

### Q13. What is a Scatter Plot?

**Answer:** Scatter Plot do numerical variables ke beech relationship show karta hai.

### Q14. What is a Histogram?

**Answer:** Histogram numerical data ki frequency distribution ko bars ke through represent karta hai.

### Q15. What is a Treemap?

**Answer:** Treemap rectangles ki help se data ko represent karta hai. Rectangle ka size data ki value show karta hai.

### Q16. What is a Geographic Map?

**Answer:** Geographic Map geographical data jaise State, Country aur City ko map par display karta hai.

# 3\. Data Preparation Questions

### Q17. What is Data Cleaning?

**Answer:** Data Cleaning mein hum missing, duplicate aur incorrect data ko identify karke correct karte hain.

### Q18. What is Data Preparation?

**Answer:** Data Preparation mein data ko clean, organize aur analysis ke liye ready kiya jata hai.

### Q19. What is a Join?

**Answer:** Join ka use do tables ko ek common field ki help se combine karne ke liye hota hai.

### Q20. What are the types of Joins?

**Answer:** Join ke 4 types hain:

1. Inner Join
2. Left Join
3. Right Join
4. Full Outer Join

### Q21. What is a Union?

**Answer:** Union ka use multiple tables ki rows ko combine karne ke liye hota hai.

### Q22. What is Data Blending?

**Answer:** Data Blending ka use different data sources ko ek common field ki help se combine karne ke liye hota hai.

### Q23. What is a Filter?

**Answer:** Filter ka use required data ko display karne aur unwanted data ko exclude karne ke liye hota hai.

### Q24. What is a Data Extract?

**Answer:** Data Extract original data ki stored copy hoti hai jiska use faster analysis ke liye kiya jata hai.

### Q25. What is the difference between Live and Extract?

**Answer:** Live connection directly original data source se connect hota hai, jabki Extract data ki stored copy use karta hai.

# 7\. Important Tableau Formulas

## 1\. Profit Ratio

``` tableau
SUM([Profit]) / SUM([Sales])
```

## 2\. Sales Category

``` tableau
IF [Sales] >= 1000 THEN "High"
ELSE "Low"
END
```

## 3\. Discount Classification

``` tableau
IF [Discount] > 0.2 THEN "High Discount"
ELSE "Low Discount"
END
```

## 4\. Replace Null Values

``` tableau
IFNULL([Category], "Unknown")
```

## 5\. Remove Extra Spaces

``` tableau
TRIM([Category])
```

## 6\. Extract Year from Date

``` tableau
YEAR([Order Date])
```

## 7\. Extract Month from Date

``` tableau
MONTH([Order Date])
```

## 8\. Profit Status

``` tableau
IF [Profit] > 0 THEN "Profit"

ELSEIF [Profit] < 0 THEN "Loss"

ELSE "No Profit"
END
```

## 9\. Running Total

``` tableau
RUNNING_SUM(SUM([Sales]))
```

## 10\. Moving Average

``` tableau
WINDOW_AVG(SUM([Sales]), -2, 0)
```

### Basic Steps to Create a Chart

1. Tableau open karo.
2. Dataset connect karo.
3. Required Dimension ko Columns mein drag karo.
4. Required Measure ko Rows mein drag karo.
5. Show Me se chart select karo.
6. Title, colors aur labels customize karo.

# 9\. Dashboard Creation – Steps

1. Sabse pehle 2–3 Worksheets par charts banao.
2. New Dashboard par click karo.
3. Left side se worksheets drag karke dashboard mein add karo.
4. Filters add karo — Region, Category, Order Date.
5. Worksheet dropdown se **Use as Filter** select karo.
6. Dashboard ka title add karo.
7. Colors, layout aur formatting improve karo.
8. Dashboard ko save ya publish karo.

# 11\. Last-Minute Revision Tricks 🧠

## Tableau = C-D-M-A-S

- **C** — Connect Data
- **D** — Dimensions \& Measures
- **M** — Make Charts
- **A** — Analyze Data
- **S** — Share Dashboard

## RFM = R-F-M

- **R** — Recency
- **F** — Frequency
- **M** — Monetary Value

## LOD = F-I-E

- **F** — FIXED
- **I** — INCLUDE
- **E** — EXCLUDE

## Join = I-L-R-F

- **I** — Inner
- **L** — Left
- **R** — Right
- **F** — Full Outer
